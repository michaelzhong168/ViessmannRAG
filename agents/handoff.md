# 任务交接模板

Reader 建立交接记录，Coder 和 Reviewer 沿用同一任务与验收编号。按项目指定的位置分别保存计划、交付和评审记录。位置未指定时，在任务对话或任务跟踪记录中交接。

| 字段 | 内容 |
| --- | --- |
| 任务来源及版本 | 任务 ID 或标题、规格 / Issue / 用户说明的位置与版本。无版本号时记录提交、修订时间或固定的任务说明。共享契约另记来源与版本。 |
| 验收项 | 每项记录需求 ID 或条款位置、预期行为、验证手段和证据。标明项目允许后续人工确认的项目及负责人。 |
| 基线与被审快照 | 用提交 SHA 或等效标识固定基线和目标。若包含未提交改动，明确纳入范围并提供同一份可复查快照。 |
| 验证命令 | 记录命令、必要运行条件、退出结果。人工检查记录步骤和预期结果。 |
| 证据位置 | 链接到测试输出、产物或可复查记录。敏感内容经遮蔽后分享并标注。 |

计划可记录待实现的测试和预期证据，交付与复核须补上实际结果。版本或快照变化时，标注变化并重跑受影响的检查。
